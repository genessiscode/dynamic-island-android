# Dynamic Island for Android — releases

Public release feed for Dynamic Island for Android. The app source repository is private; this
repository only carries the signed APK, `update.json`, and release notes.

[**Download the latest APK**](https://github.com/genessiscode/dynamic-island-android/releases/latest)

## Install

1. Download `DynamicIsland-X.Y.Z.apk` from the latest release.
2. Open it and allow installs from this source if Android asks.
3. Grant notification access and accessibility access on first launch.

The built-in updater and Obtainium read:
`https://github.com/genessiscode/dynamic-island-android/releases/latest/download/update.json`

See [CHANGELOG.md](CHANGELOG.md) for release notes.
